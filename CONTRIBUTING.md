# Contributing

This repository is a curated educational catalog.

## Add or replace a repo

1. The link must be a public GitHub repository.
2. It must clearly implement or survey the topic section you are editing.
3. Prefer maintained code with a README that runs.
4. Keep **five** entries per topic. If you add one, remove the weakest.
5. Update both `README.md` and `catalog/repos.json`.

## Style

- Short “why it is here” lines, not marketing copy.
- No copied paper PDFs or vendored third-party code.
- Demo images must be attributed and linked, not re-hosted unless you have rights.
